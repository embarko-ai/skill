# Embarko documentation

The platform reference lives at **https://embarko.ai/doc** — the full API,
authentication, anonymous deploys, status and logs, environment variables,
memory, rollback, custom domains, and the error-code table.

It is the single canonical source, maintained with the platform itself.
This file used to be a second copy of it and drifted out of date; nothing
is duplicated here any more so that can't happen again.

For this skill specifically:

- `SKILL.md` — how to deploy (what an agent needs, nothing more).
- `scripts/troubleshoot.md` — failure modes and their fixes.
- https://embarko.ai/troubleshoot — the full platform troubleshooting reference.

If the docs and the live API ever disagree, trust the live API.
